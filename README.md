# Голосовой пульт

Телефон (кнопка «держи») → сайт на Render → `agent.py` на твоём ПК → **DeepSeek Harness (`dsh --profile headless`)** выполняет задачу → ответ (и скриншот, если просил) приходит на телефон.

## 1. Render
1. Залей папку в GitHub (репозиторий), на render.com → New → Blueprint (подхватит `render.yaml`).
2. Переменные окружения:
   - `APP_TOKEN` — твой длинный пароль
   - `STT_KEY` — бесплатный ключ Groq (console.groq.com) для распознавания голоса
3. Открой `https://ТВОЙ-САЙТ.onrender.com`, введи `APP_TOKEN`. «Поделиться → На экран Домой» — будет как приложение.

## 2. Агент на ПК (Windows)
Сначала проверь, что dsh работает сам: `npx -y @deepseek-ai/dsh --profile headless "привет"` (ключ DeepSeek уже должен быть настроен в dsh).
Если у тебя dsh стоит иначе, задай `set DSH_CMD=dsh --profile headless`.

```
pip install -r agent_requirements.txt
set SERVER=https://ТВОЙ-САЙТ.onrender.com
set APP_TOKEN=твой_пароль
set WORKDIR=C:\папка_с_проектами
set TASK_TIMEOUT=900
python agent.py
```
Пока агент запущен, он же не даёт бесплатному Render засыпать. Скриншот агент добавляет сам, если в запросе есть «скрин / скин / экран». dsh получает последние 3 запроса как контекст. Любой, у кого есть `APP_TOKEN`, управляет твоим ПК через dsh — держи его в секрете.

## 3. Быстрая кнопка iPhone (Shortcuts)
Команда «Пульт»:
1. **Записать аудио** — Начало: сразу, Конец: по нажатию.
2. **Получить содержимое URL** — `https://ТВОЙ-САЙТ.onrender.com/api/voice?wait=1`, метод POST, заголовок `Authorization` = `Bearer ТВОЙ_ПАРОЛЬ`, тело: Форма, поле `audio` типа Файл = записанное аудио.
3. **Получить значение словаря** `reply` → **Произнести текст** (или Показать результат).

Привязка: Настройки → Универсальный доступ → Касание → Тап по задней панели (или Кнопка действия → Команда → «Пульт»). Запись идёт, пока не нажмёшь «Готово».
